# Chronicle

A 3D walkable museum I built just for fun while learning about different eras and categories of history.

Four wings so far: Politics & Power, Science & Technology, Media & Literacy, and Culture & Beliefs. Walk around, open doors, read the exhibits.

It's one single HTML file. Just open `index.html` in a browser.

**Controls:** WASD to move, Shift to sprint, right-click drag to look around, click or press E to open an exhibit.

Built with Three.js.
